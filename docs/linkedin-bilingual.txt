Project 2/6: LogLens — Network Log Analyzer

• CSV and Apache common/combined access log import, with invalid-row reporting.
• Request timeline, unique clients, response status families, transfer totals, and top IPs.
• Searchable, paginated request table, filtered CSV export, and explainable threshold-based signals.

Stack: JavaScript, HTML, CSS, browser APIs.
Includes automated tests for the core logic.
This is a client-side learning tool; its signals are simple heuristics, not security verdicts.

Source code and setup: https://github.com/MahtaRahmati/loglens

Feedback and code reviews are welcome.
